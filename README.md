# Fed Explorer
is a high-performance, client-side Roblox instance explorer engineered for runtime inspection, rapid environment debugging, and lightweight development workflows. Designed as a lean alternative to heavier execution and inspection suites like [Dex Explorer](https://github.com/LorekeeperZinnia/Dex/tree/master), it focuses on delivering core object inspection features without unnecessary overhead.

## Overview

Fed Explorer offers a streamlined interface for real-time interaction with the Roblox data model from the client environment. It provides essential debugging capabilities for developers and testers who need immediate visibility into game hierarchies, instance properties, and client-side states without cluttering their workspace or compromising game performance.

## Features

* **Client-Side Data Model Traversal:** Explore, search, and navigate through accessible client-side instances in real time.
* **Property & State Inspection:** View runtime property values, attributes, and object states directly during execution.
* **Minimal Performance Impact:** Built with a lightweight footprint to preserve frame rates and minimize memory usage during active sessions.

## Usage

**Important Setup Step:** Before running Fed Explorer for the first time, you must extract the contents of `Fed.zip` directly into your executor's `workspace` folder. This ensures all required assets, icons, and image dependencies render correctly within the interface.
